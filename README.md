# Awesome-chocolates-sql-powerbi-project
Awesome chocolates sales analysis using Mysql and Power BI. Practised SQL concepts including aggregations, group by, join, subqueries, CTE's, and window functions. Created an interactive Power BI sales dashboard.

# Project Overview
This project focuses on analysing the Awesome Chocolates sales dataset using Mysql and PowerBI.
Mysql was used to practice sql queries and explore sales data using different sql concept. PowerBI was used to create an interactive sales dashboard with visualisations and key performance indicators(KPIs).

# Tool used
- Mysql workbench
- Power BI
- SQL

# Sql Concepts practised
- Aggregate functions
- Group by and Having
- joins
- Subqueries
- CTE
- Window functions
- CASE statement
- Percentage Calculations

# Power BI Dashboard
Developed a two-page interacticve powerBI sale report to analyse sales performance, shipment metrics, product performance, and regional sale distribution.

Page 1: Overview
Key performance indicators
- Total sales
- Total boxes
- Shipment count
- Low boxes percentage

Visualisations
- Sales Trend: Line chart showing sales trends over time.
- Sales by Geography: Bar chart comparing sales across geographical areas.
- SalesPerson Performance: Table displaying Total sales, Total Boxes, and low boxes percentage for each salesperson.
- Sales by product: Donut chart showing the distribution of sales across products.

Page 2: Sales Analysis
Visualisations:
- Sales by Region: column chart comparing sales across regions.
- Sales by Category: Funnel chart visualising sales across categories.
- Sales Target: Gauge chart displaying sales performance against sales across.
- Sales by Category and Product: Treemap visualising sales across categories and product.
- Sales Distribution by Year and Location: Stacked column chart comparing sales across year and locations.
